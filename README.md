One line roasting the smart fridge I share a kitchen with: it nags about a door left open for half a minute, yet keeps its real observations for the manufacturer. `main.ts` checks the line against the 160-character gate and writes it, with no trailing newline, to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat out/entry.txt
```
